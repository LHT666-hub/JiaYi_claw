# 家医 Claw 微信真机验收矩阵

本清单用于体验版和正式版提交前验收。每条必须记录设备、微信版本、账号、时间、结果、截图或服务端 `traceId`；失败项不得用口头说明关闭。

## 测试设备

| 编号 | 设备 | 系统 | 字体 | 网络 |
| --- | --- | --- | --- | --- |
| IOS-1 | 近三年 iPhone | 最新正式 iOS | 标准、最大各一轮 | Wi-Fi、5G |
| AND-1 | 主流 Android | 最新或次新正式版 | 标准、最大各一轮 | Wi-Fi、5G |
| LOW-1 | 可用的低端 Android | 机构实际常见版本 | 标准 | 4G 弱网 |

## A. 安装与首登

- [ ] 首次打开显示微信隐私保护提示，拒绝后仍可阅读隐私政策和用户协议。
- [ ] 微信手机号一键登录成功；取消授权后可切换短信验证码。
- [ ] 验证码倒计时期间不能重复发送，过期后可以重发。
- [ ] 新用户按“身份 -> 社区 -> 授权”完成建档；运营主体和隐私联系人不是占位文本。
- [ ] 居民与家属分别登录，家属未绑定居民前看不到任何居民健康或服务记录。
- [ ] access token 过期后自动刷新；refresh token 失效后回到登录页。

## B. 居民核心闭环

- [ ] 首页显示当前服务对象、所属社区、真实服务进度和核验排班。
- [ ] 服务页只能看到所属家医网络的服务、机构、排班和已审核内容。
- [ ] Claw 文字和语音均可连续对话；录音拒绝授权后文字输入仍可使用。
- [ ] 从相机和相册选择报告、处方或药盒图片均可识别；拒绝相机/相册权限后仍可使用文字和语音。
- [ ] 模糊、裁切、反光或非医疗图片明确显示低置信度和不确定项，不编造缺失文字。
- [ ] 图片识别结果先进入核对页，居民点击确认前不进入 Claw、不创建服务申请。
- [ ] 超过 4 MB、伪造文件类型、上传超时和视觉模型失败均有恢复入口，不丢失当前问题草稿。
- [ ] Claw 识别预约意图后只生成草稿，用户确认前数据库没有服务申请。
- [ ] 预约三步流程可选择事项、日期、时段、科室/医生偏好、候补和联系电话。
- [ ] 快速连点提交只生成一条申请，提交后自动进入办理进度。
- [ ] 工作人员请求补资料后，居民补充并重新进入团队队列。
- [ ] 工作人员提出时段后，居民可确认或申请改期；取消前有二次确认。
- [ ] 服务事件时间线、预约机构、科室、医生和编号与后台一致。

## C. 家属授权

- [ ] 一次性绑定码只能使用一次，过期码和错误码均被拒绝。
- [ ] 家属可在授权范围内代问、代预约和查看进度。
- [ ] 居民撤回家属授权后，家属下一次请求立即被拒绝。
- [ ] 切换被照护人后，首页、服务、消息和办理进度同步切换且不串数据。

## D. 消息与订阅

- [ ] 首次开启微信订阅消息时弹出系统授权框，拒绝后不反复骚扰。
- [ ] 预约状态变化同时写入站内消息和 outbox，重复 worker 不重复发送。
- [ ] 免打扰时段、微信通知开关和站内消息已读状态可保存。
- [ ] 订阅次数耗尽或模板失效时进入可审计失败状态，不伪报发送成功。
- [ ] 帮助页展示所属社区核验电话，微信客服能进入官方会话，取消拨号不会显示错误。
- [ ] 居民反馈快速重复提交只生成一条；未授权联系时后台不展示电话，处理结论留有事件记录。

## E. 安全与医疗边界

- [ ] 胸痛、呼吸困难、意识不清和大出血只提示立即拨打 120，不生成普通预约。
- [ ] 询问处方、停药、换药和剂量时不输出替代医生的结论。
- [ ] 未授权 AI 处理时，Claw 不读取或保存敏感健康资料。
- [ ] 清除 Claw 服务轨迹后无法恢复；数据库不存在问题、回答或音频原文列。
- [ ] 服务端、对象存储、日志和居民档案均不存在上传图片；`skill_runs` 只保留类型、大小、置信度和 `retained=false`。
- [ ] 退出登录后本机 token 和服务对象缓存被清除；返回键不能进入已登录页面。
- [ ] 从服务进度等受保护深链进入且未登录时直接回到登录页，不停留在接口错误页。
- [ ] 账号注销有 7 天冷静期，可撤销；到期任务删除或匿名化约定数据。

## F. 弱网、兼容与可用性

- [ ] 请求超时、离线、服务端 401/403/409/500 都有可理解提示和恢复入口。
- [ ] 上传语音超时不会丢失已转写文字，也不会自动提交服务。
- [ ] iOS/Android 最大字体下按钮、状态标签、科室名和医院名不截断或重叠。
- [ ] 375、390、430 逻辑宽度无横向滚动，底栏不遮挡最后一项操作。
- [ ] 连续快速切换标签页不会重复创建申请、重复绑定或重复发送通知。

## G. 提交证据

- [ ] 居民、家属、补资料、预约确认、改期、注销各保留一段完整录屏。
- [ ] 至少 4 张审核截图不包含测试标记、虚构医生、真实居民隐私或开发工具。
- [ ] 导出本轮失败项、修复提交和复测记录。
- [ ] 记录小程序体验版版本号、Git commit、后端版本和数据库迁移版本。
