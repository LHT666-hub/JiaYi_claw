# 家医 Claw 微信发布操作手册

这份手册用于把代码构建转成可导入微信开发者工具的正式小程序。仓库中的 `touristappid` 只供无资质预览，不能提交审核。

## 1. 准备微信后台

1. 在微信公众平台取得已认证主体的 AppID 和 AppSecret。
2. 按实际服务申请小程序类目。首版表述为服务导航、家庭医生协同和资料整理，不申报 AI 诊断、处方或互联网诊疗。
3. 在“开发管理 -> 开发设置 -> 服务器域名”加入：
   - `request`：`https://lht11.me`
   - `uploadFile`：`https://lht11.me`
   - `downloadFile`：`https://lht11.me`
4. 在“设置 -> 基本设置 -> 服务内容声明 -> 用户隐私保护指引”按实际能力声明：手机号、麦克风、所选照片或视频、摄像头、健康信息和设备日志。
5. 在客服设置中绑定真实接待人员；代码里的“微信客服”按钮只有完成后台配置后才能进入会话。
6. 选用一次性订阅消息模板，记录模板 ID 与字段名称。预约和服务状态至少需要事项、状态、更新时间和备注四个字段。

## 2. 填写正式环境

从 `.env.production.example` 创建 `.env.production.local`，填入正式值。该文件已被 Git 忽略，不得提交。

```powershell
Copy-Item .env.production.example .env.production.local
npm run check:release
```

`check:release` 会拒绝测试开关、HTTP 地址、占位 AppID、弱 cron 密钥、错误短信 Hook 密钥和无效订阅字段。

## 3. 生成正式小程序包

```powershell
npm run build:release
```

该命令依次执行环境检查、生成 `apps/wechat/project.private.config.json`、Web 构建、小程序构建和严格包验证。严格验证要求：

- 19 个居民页面和四栏导航完整。
- 每个页面有正式标题和编译产物。
- 全局微信隐私授权、客服反馈和订阅消息闭环存在。
- 不包含开发登录、体验账号或占位 API 域名。
- 主包不超过 2 MB。

## 4. 导入与体验版

1. 微信开发者工具选择“导入项目”，目录为 `apps/wechat`。
2. 核对详情页 AppID 为正式值、`urlCheck=true`、基础库为当前稳定版。
3. 在开发者工具中分别测试清缓存首次打开和保留授权再次打开。
4. 上传体验版，版本号使用 `日期.序号`，备注同时记录 Git commit 和数据库迁移版本。
5. 配置体验成员，在 iPhone、Android 和弱网设备执行 `WECHAT_DEVICE_ACCEPTANCE.md`。

## 5. 提交审核

审核材料必须使用真实机构信息，不虚构医生、医院关系或号源。审核路径建议写明：

1. 微信手机号登录，取消时可改用短信验证码。
2. 选择居民或家属身份，完成社区与隐私授权。
3. 首页查看家医团队；未核验用户仍可查看公开服务信息。
4. 服务页查看排班、活动与家医课堂，点击来源可打开原文。
5. 预约只创建人工协同申请，团队确认后居民再确认时段。
6. “我的 -> 帮助与反馈”可联系社区、微信客服和提交反馈。
7. “我的 -> 账号与隐私”可撤回授权并申请注销。

提交前将 `RELEASE_CHECKLIST.md` 全部阻断项关闭。真实 AppID、短信签名、服务类目、备案域名、机构协议和微信审核不能由代码替代。
